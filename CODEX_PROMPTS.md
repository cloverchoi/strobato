# CODEX PROMPTS

## Prompt 1

Build the first prototype of the Strobato SDK.

Requirements:
- Python package
- MusicXML parser
- simulated note matching
- current measure inference
- confidence score
- page-turn signal

Keep architecture modular and beginner-friendly.

## Prompt 2

Add real microphone input for piano note detection.

The system should:
- listen to live audio
- detect notes in real time
- feed notes into the synchronization engine
